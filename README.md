# LACTBL1 Notes

Overview and raw-data portal for the human gene **LACTBL1** (beta-lactamase-like protein 1, NCBI Gene 646262).
Semester gene project for GCD 3485 Bioinformatic Analysis (University of Minnesota, Fall 2026).

- Site: https://mike-zhiyuan.github.io/lactbl1/ (English) · https://mike-zhiyuan.github.io/lactbl1/zh.html (中文)
- Contents: locus and exon structure, mRNA and protein domains, expression, evolution (orthologs and paralogs, invertebrate orthology tests, rate of evolution, duplication time, most conserved residues), literature, and direct links to the raw records in NCBI, UniProt, Ensembl, HPA and other databases
